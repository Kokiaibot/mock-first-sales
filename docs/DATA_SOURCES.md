# データソースの採否と利用条件（2026-11-08 確認）

| データソース | 採否 | 内容・条件 | 公式サイト URL |
|---|---|---|---|
| ユーザー提供 CSV | **採用（実装済み）** | 取込時に「利用許諾・再利用条件を満たす」確認を必須化。行ごとに利用条件を記録 | CSV の列に含まれる場合のみ |
| gBizINFO REST API（経済産業省・デジタル庁） | **採用（トークン待ち）** | 無料・Web API 利用申請でトークン発行。ヘッダ `X-hojinInfo-api-token`。出典表示が必要 | 記載がある法人のみ。ない場合は除外 |
| 法人番号システム Web-API（国税庁） | 未実装（補助用途） | 無料・アプリケーション ID の届出が必要。法人番号・商号・所在地のみ | 含まれない |
| 法人番号 全件ダウンロード | 未実装 | 登録不要。名寄せ用途 | 含まれない |
| Google Places API | **不採用** | 有料。place_id 以外のコンテンツの保存・キャッシュ・事前取得が制限され、営業リストへの保存用途に適さない | — |
| Google Maps の一括取得 | **実装しない** | 利用規約違反 | — |
| 検索エンジン結果からの URL 推定 | **実装しない** | 推測 URL を公式サイトとして確定しない方針 | — |

## 公式サイト URL がない場合
1. 企業は「公式サイトURLなし」として送信対象外（除外）になります。
2. 利用者が公式サイトを確認できた場合のみ、企業詳細で URL を登録 → 分析で HTTP 応答を確認。
3. 自動で公式と確認できるのは「最終 URL のドメインが登録ドメインと一致し、ページ内に企業名がある」場合だけ。それ以外は「HTTP応答あり・公式性未確認」となり、利用者が根拠を入力して確定します。

## 取得時の配慮
- User-Agent を明示、同一ホストへは 1 秒以上間隔、robots.txt を尊重、1 社あたり最大 5 ページ、応答 3MB・15 秒で打ち切り。
- 403 は回避せず終了、429/503 は Retry-After に従って再試行。
