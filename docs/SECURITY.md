# セキュリティ・データ保護

## 接続と認証
- 既定で `127.0.0.1` のみで待ち受け。ローカル以外の HOST は `ALLOW_REMOTE=1` がないと起動しません（外部公開は非推奨。公開する場合は HTTPS リバースプロキシの背後に置くこと）。
- Host ヘッダを検証（DNS リバインディング対策）。公開 URL のホストはプレビュー（`/p/`）と配信停止（`/u/`）にだけ許可。
- 初期設定で管理者を作成（12 文字以上・英数字混在、scrypt でハッシュ化）。ログイン 5 回失敗で 5 分ロック。
- セッションは HttpOnly・SameSite=Strict Cookie、DB には SHA-256 ハッシュで保存、12 時間で失効。パスワード変更で全セッション破棄。

## Web の脆弱性対策
| 対策 | 実装 |
|---|---|
| CSRF | 全 POST でセッション固有トークン＋Origin 検証、SameSite=Strict |
| XSS | 全出力を自動エスケープするテンプレート、管理画面 CSP `script-src 'none'`、URL 属性は http(s) のみ |
| SSRF | URL スキーム/ポート制限、名前解決結果をすべて検査し内部 IP（IPv4/IPv6/IPv4-mapped）を拒否、検査済みアドレスに固定して接続、リダイレクトごとに再検査、ブラウザの全リクエストを `route` で検査 |
| パストラバーサル | スクリーンショット・EML は DB に登録したファイル名（形式検証済み）だけを配信。固定サイトはルート外を拒否 |
| ヘッダインジェクション | EML の宛先・件名から改行を拒否／除去 |
| CSV 数式インジェクション | 取込時は数式様の値を拒否、出力時は先頭に `'` を付与 |
| クリックジャッキング | `frame-ancestors 'self'` |

## 秘密情報
- gBizINFO トークン等は管理画面から入力し `data/secrets.json`（権限 600）に保存。画面には「設定済み」のみ表示、ログに出さない。
- 環境変数 `MFS_GBIZINFOTOKEN` でも指定可能。チャットやソースコードに値を貼らないでください。
- `data/`（DB・画像・EML・鍵）は `.gitignore` 済み。バックアップは既定で秘密情報を含めません。
- Windows では `data/` を利用者プロファイル配下に置くと他ユーザーから読めません。暗号化が必要な場合は BitLocker を利用してください（本アプリ自体は DB を暗号化していません）。

## 外部 AI への送信
- AI 連携は既定で無効。有効にしても、実行ごとに**送信される全文・送信先・必要性・費用区分**を表示し、同意チェックがないと送信しません。
- 外部サイト本文と AI 出力は「データ」として扱い、プロンプト内でも指示に従わないよう明示。AI 出力は JSON・長さ・必須事実（URL・閲覧コード・署名・配信停止）を検証し、欠落があれば採用しません。
- Claude Code は `claude -p` を空の一時フォルダで実行し、ファイル操作・コマンド実行・Web 取得のツールをすべて禁止、1 ターンのみ、MCP サーバーは読み込みません。`ANTHROPIC_API_KEY` / `ANTHROPIC_AUTH_TOKEN` は渡しません。
- Codex は読み取り専用サンドボックス・一時ディレクトリで実行。どちらも権限スキップのオプション（`--dangerously-skip-permissions` 等）は使いません。

## 送信制御
- 承認なしの送信、営業リスト外（企業に登録されたアドレス以外）への送信、配信停止先・重複送信を拒否。送信直前に再確認。
- 結果不明は「要確認」で自動再送しない。起動時に「送信中」のまま残ったものは「要確認」に変更。
- CAPTCHA 回避、403/429 等の回避は実装していません。429/503 は Retry-After に従い待機。robots.txt を尊重。
