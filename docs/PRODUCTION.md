# 受注後の本制作への引き継ぎ

モックは仕様（JSON）から描画しているため、本制作の起点として取り出せます。

1. 企業詳細 → モック「プレビュー・比較」で内容を確認。
2. 管理画面の「モックを全画面で開く」から各ページ（トップ／サービス／お問い合わせ）をブラウザの「名前を付けて保存」で HTML として保存（CSS は HTML 内に含まれ、外部リソースはありません）。
3. DB の `mocks.spec` に、配色・見出し・サービス・構成・改善方針・素材の出典が保存されています（`npm run backup` のファイルを SQLite ツールで参照）。
4. 本制作で差し替えが必要な箇所:
   - 「掲載予定領域」（実績・事例・写真）→ 顧客から許諾を得た素材
   - サービス説明（テンプレート案）→ ヒアリング内容
   - 所在地の詳細、料金、診療方針など
   - デモの問い合わせフォーム → 実際の送信先・個人情報保護方針
5. 試作プレビューは受注後に失効させてください（モック画面の「失効させる」）。

※ 本制作用のエクスポート機能（ZIP 出力等）は未実装です。
