# 外部閲覧可能なプレビュー（承認後の作業・未実装）

現在、プレビュー URL は `http://127.0.0.1:8787/p/<token>/` のローカル URL のみで、相手先からは閲覧できません。営業文の品質チェックでも警告が出ます。

公開環境へのデプロイは**利用者の承認後**に行う作業です。想定している方式と必要な判断:

| 方式 | 概要 | 費用 | 判断事項 |
|---|---|---|---|
| A. 静的書き出し＋ホスティング（Vercel 等） | 承認済みモックだけを HTML として書き出し公開。閲覧コードはエッジ側で検証 | 無料枠あり（超過時は各社の料金） | 書き出し機能の実装が必要（未実装） |
| B. リバースプロキシで `/p/` と `/u/` のみ公開 | Cloudflare Tunnel 等で本アプリの公開パスだけを外部に出す | 無料枠あり | PC を起動し続ける必要。管理画面が外部から見えないよう Host 制限を利用（実装済み） |

B の場合の設定例（承認後）:
```powershell
$env:PUBLIC_BASE_URL="https://preview.example.com"
npm start
```
`PUBLIC_BASE_URL` のホストに対しては `/p/`（プレビュー）と `/u/`（配信停止）以外は 421 で拒否されます。営業文には外部 URL と配信停止ページが記載されます。
